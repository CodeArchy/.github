# Getting help

- **Questions and how-tos:** [GitHub Discussions → Q&A](https://github.com/CodeArchy/codearchy/discussions)
- **Bugs:** [open a bug report](https://github.com/CodeArchy/codearchy/issues/new/choose)
- **Feature ideas:** [Discussions → Ideas](https://github.com/CodeArchy/codearchy/discussions) or a feature request issue
- **Security issues:** see [SECURITY.md](SECURITY.md). Please don't post them publicly.
- **Anything else:** [support@codearchy.com](mailto:support@codearchy.com)

Before opening an issue, please search existing issues and discussions. Someone may already have asked.
