# CodeArchy

**See how any codebase is built.** CodeArchy turns source code into an explorable architecture diagram that you can ask questions about. It runs locally, so your code stays on your machine.

| Repository | What it is |
|---|---|
| [**codearchy**](https://github.com/CodeArchy/codearchy) | The VS Code extension: parsing, dependency graph, architecture diagrams, AI chat and voice narration |
| [**codearchy-web**](https://github.com/CodeArchy/codearchy-web) | The [codearchy.com](https://codearchy.com) website |

### Get started

- Install from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=iyinusa.codearchy)
- Read the [contributing guide](https://github.com/CodeArchy/codearchy/blob/main/CONTRIBUTING.md). We welcome contributions of every size.
- Ask questions or share ideas in [Discussions](https://github.com/CodeArchy/codearchy/discussions)
